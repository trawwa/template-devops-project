# template-devops-project
Full DevOps Service in 1 Project


Проект для определения универсального DevOps сервиса.

В качестве app будет приложение-соцсеть. В принципе можно использвоать любое приложение.

## Структура

```
.
├── app/
│   └── main.py
├── docker/
│   └── Dockerfile
├── k8s/
│   └── deployment.yaml
├── terraform/
│   └── main.tf
├── monitoring/
│   └── prometheus.yml
├── ci/
│   └── pipeline.yml
└── README.md
```
